# Archived logo files

The badge in the formats the site used to show on its pages. No page uses these
now, and this folder is not published (see `.vercelignore`), but they are kept:

- `logo.svg` is the vector master. `../share-1200x630.png`, the link preview
  image, was drawn from it with the white background recolored to the site's
  paper tone.
- `logo-340.jpg`, `logo-680.jpg`, `logo-1020.jpg` are raster sizes, metadata
  stripped.
